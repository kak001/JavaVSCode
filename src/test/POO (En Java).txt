POO (En Java)

Conceptos basicos

¿Que es la Programacion Orientada a Objetos (POO)?
Es un modelo de programacion basado en el concepto de "objetos", que son estructuras de datos que combinan
propiedades y comportamientos.

Modela entidades
Representan cosas del mundo real (Ej: Animal, Usuario) en el codigo.

Datos y comportamientos
Agrupa atributos (estados) y metodos (comportamientos) en una sola unidad.

Mejora reutilizacion
Facilita la creacion de codigo escalable, modular y facil de mantener.

Todo en Java es un objeto (o casi todo).

============================================================================================================================================

Clase vs Objeto 

Clase = Plantilla
El molde o el plano (Ej: Concepto Animal).

Objeto = Instancia
La creacion real en memoria (Ej: "Mi perro Max").

Atributo = Estado 
Datos que el objeto guarda (nombre, edad, raza, etc).

Metodos = comportamientos
Acciones que el objeto puede hacer (comer, sonido, dormir, etc).

============================================================================================================================================

¿Que son los Atributos?

El Estado del Objeto

Los atributos (O variables de instancia) son las caracteristicas que describen el estado actual de un objeto.
Definen "Lo que un objeto tiene".

Nombre
Identificador del objeto (Ej: "Arenita", "Luna", "Happy", etc).

Edad 
Dato numerico del objeto (Ej: 6, 8, 2).

Peso
Medida fisica del objeto (Ej: 4.8 kg, 6.1 kg, 4.5 kg, etc).

============================================================================================================================================

Metodos en POO

Los metodos son funciones que le pertenecen a una clase. Definen "Lo que puede hacer el objeto" y como interactua
con sus datos.

comer()
Accion que puede modificar el atributo 'peso'.

dormir()
Accion que cambia el estado a 'descansando'.

hacerSonido()
Emite un sonido en especifico ("¡Meow!").

============================================================================================================================================

¿Que es un Constructor?

Un constructor es un bloque de codigo especial que se ejecuta cuando se crea un nuevo objeto. Se utiliza para 
inicializar los atributos de ese objeto.

Inicializacion
Prepara el objeto dandole valores iniciales a sus atributos.

Mismo Nombre
Debe llamarse exactamente igual que la clase (Ej: Animal).

Sin Tipo de Retorno
No devuelve ningun valor, ni siquiera void.

Importante: Si no se crea uno, Java proporciona un constructor por defecto vacio.

============================================================================================================================================

El uso de "this" en Java

¿Para que sirve?

La palabra reservada "this" en Java es una referencia al objeto actual en el que se esta ejectuando el codigo.

Objeto actual
Referencia a la instancia que invoca el metodo o constructor.

Diferenciar variables
Permite distinguir entre un atributo de la clase y un parametro con el mismo nombre.

Reutilizar constructores
Se puede usar this() para llamar a otro constructor de la misma clase.

Buena practica:
Siempre usa this cuando un parametro eclipse (oculte) a un atributo de la clase.

============================================================================================================================================

Encapsulamiento en Java

¿Que es el Encapsulamiento?

Consiste en ocultar el estado interno de un objeto (sus atributos) y requerir que toda interaccion se realice a traves de metodos publicos.

1. Atributos Privados
Usar private evita que se modifique directamente desde fuera de la clase.

2. Metodos Setters
Permiten modificar el valor aplicando validaciones y reglas.

3. Metodos Getters
Metodos publicos deseñados para leer el valor de forma segura.

Buena practica: Los atributos deben ser privador por defecto.

============================================================================================================================================

Modificadores de Acceso

Niveles de Visibilidad

Java usa modificadores para determinar que otras clases pueden usar un atributo o metodo.

private: Solo visible dentro de la misma clase. Maxima restriccion.

default (sin palabra): Visible para clases dentro del mismo paquete.

protected: Visible en el mismo paquete y subclases.

public: Visible desde cualquier clase. Minima restriccion.

Buena practica: Atributos private y metodos public

============================================================================================================================================

Herencia en Java

¿Que es la Herencia?

La herencia permite crear nuevas clases (subclases) basadas en clases existentes (superclases). Establece una relacion "Es un".

Reutilizacion
Atributos y metodos se herendan automaticamente.

Especializacion
Las subclases añaden o modifican comportamientos.

Relacion "Es un".
Un Perro "Es un" Animal.

Palabra Clave: extends

============================================================================================================================================

Polimorfismo

¿Como funciona?

1. Referencia General
Usamos una variable del tipo de la superclase (Ej: Animal).

2. Objeto Especifico
A esa variable le asignamos un objeto real de una subclase (Ej: new Perro()).

3. Ejeccion Dinamica
Al llamar a un metodo, Java decide en tiempo de ejecucion que version usar dependiendo del objeto real creado.

Beneficio: Permite escribir codigo mas generico, flexible y facil de extender sin modificar lo existente.

============================================================================================================================================

Abstraccion: Ocultando Detalles

¿Que es la Abstraccion?

Mostrar lo Esencial
LA abstraccion expone solo los detalles relevantes de un objeto, ignorando la complejidad subyacente.

Ocultar Implementacion
El usuario del objeto no necesita saber como realizar una accion, solo que accion realiza.

Clases y Metodos Abstractos
En Java, se usa la palabra clase abstract. Las clases abstractas no se pueden instanciar, actuan como plantillas base.

============================================================================================================================================

Sintesis Final

La Programacion Orientada a Objetos (POO) modela entidades reales mediante clases y objetos, aplicando 4 pilares fundamentales para construir software robusto.

Encapsulamiento & Abstraccion
Proteccion de datos y simplificacion de la complejidad.

Herencia & Polimorfismo
Reutilizacion de codigo y comportamientos dinamicos.

Estructura Base
Clases, objetos, atributos, metodos y constructores.

Resultado: Codigo mas organizado, reutilizable y mantenible.
